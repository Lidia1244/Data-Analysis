# Data-Analysis
Данный проект содержит тестовую базу данных с карточными данными и транзакциями.
На основе этих данных формируются витрицы в подсчетом различных метрик: Retention, LTV, когортный анализ и т.д. 

  Цель проекта: спроектировать хранилище для загрузки данных из источника, протянув их до слоя dds и реализовать витринный слой данных
Структура проекта:
- скрипт создания базы данных 
- s2t 
- скрипты с расчетами метрик https://github.com/Lidia1244/Data-Analysis/tree/main/SQL
